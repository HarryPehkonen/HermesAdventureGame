# Careful Play Guidance

Players often prefer to understand an item's purpose before using it, rather than experimenting blindly. This leads to more satisfying gameplay and prevents unintended consequences.

When a player asks questions like:
- "What does this do?"
- "Is there any information anywhere that would help us adjust X?"
- "See if anything changed with [item]?"
- They want to understand purpose/function before action

Respond by:
1. Describing what you observe about the item based on current room state
2. Explaining its apparent purpose or function
3. Noting any visible controls, labels, or indicators
4. Mentioning what you know from examining it closely
5. Only then suggesting possible actions if they still wish to proceed

This approach respects the player's desire for informed decision-making and creates a more immersive, thoughtful gameplay experience.

## The complement: nothing to hunt for

Careful play only stays pleasant if examination is never *required*. The
Visibility & clues contract in SKILL.md is the other half of this guidance:

- Every entity is always mentioned in the room narration, so the player
  never has to ask "is there anything else here?"
- Examining scenery (nouns that are not entities) returns flavor only —
  never a discovery. Answer such examines briefly and warmly, but make it
  quietly clear there is nothing more there ("just worn grating, nothing
  behind it"), so the player learns that sweeping rooms is never needed.
- When an entity rewards closer attention, the narration says so up front
  (a clue, an odd detail, a `conspicuous` trait). Careful players should
  spend their questions on *clued* things, not on everything.

Generosity when asked, plus honesty about where depth exists, is what
removes the examine-the-doorknob grind entirely.
