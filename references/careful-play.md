# Careful Play Guidance

Players often prefer to understand an item's purpose before using it, rather than experimenting blindly. This leads to more satisfying gameplay and prevents unintended consequences.

When a player asks questions like:
- "What does this do?"
- "Is there any information anywhere that would help us adjust X?"
- "See if anything changed with [item]?"
- They want to understand purpose/function before action

Respond by:
1. Describing what you observe about the item based on current room state
2. Explaining its apparent purpose or function
3. Noting any visible controls, labels, or indicators
4. Mentioning what you know from examining it closely
5. Only then suggesting possible actions if they still wish to proceed

This approach respects the player's desire for informed decision-making and creates a more immersive, thoughtful gameplay experience.
